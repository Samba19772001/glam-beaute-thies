# Glam Beauté Thiès – site vitrine (ébauche)

Site statique : HTML, CSS et JavaScript, sans framework ni installation.

## Structure
- `index.html` : la page (accueil, services, galerie, réservation, à propos, contact)
- `css/style.css` : styles et couleurs (variables en haut du fichier)
- `js/main.js` : menu mobile, choix de teinte, filtres de la galerie, agrandissement des photos, message WhatsApp, indicateur ouvert/fermé
- `images/` : photos (issues de captures Instagram, 828 px de large)

## Voir le site
Ouvrir `index.html` dans le navigateur. Les polices viennent de Google Fonts (connexion internet nécessaire).

## Mettre en ligne (gratuit)
Glisser-déposer le dossier sur https://app.netlify.com/drop
